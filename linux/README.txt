================================================================
   Fruitcraft - PC  |  Linux  |  v0.1.11
================================================================

این بستهٔ لینوکس است. نسخهٔ ویندوز در فایل fruitcraft-v0.1.11-windows.zip
همین ریلیز است.

----------------------------------------------------------------
 اجرا
----------------------------------------------------------------
1) کل پوشه را اکسترکت کن (هر جایی که اجازهٔ نوشتن داری).

2) اگر پیش‌نیازها نبودند نصب کن:

      sudo apt install python3 python3-pil python3-tk wine64 xdotool
      #  (فدورا:  sudo dnf install python3-pillow python3-tkinter wine xdotool)

   حداقل لازم: پایتون ۳ + Pillow + Tkinter + Wine (wine64).
   xdotool اختیاری است (فقط برای تغییر نام پنجرهٔ بازی به «Fruitcraft»).

3) اجرا:

      ./Fruitcraft          (یا: python3 fruitcraft.py)

   اگر روی فایل اجرا نشد:

      chmod +x Fruitcraft && ./Fruitcraft

----------------------------------------------------------------
 چه چیزی می‌بینی
----------------------------------------------------------------
* پنجرهٔ لانچر با طرح خود بازی (پس‌زمینه، لوگو، فونت‌های خود بازی)
* چهار پروفایل، راست‌به‌چپ؛ پروفایل ۱ سمت راست است
* دکمه‌ها: شروع / ساخت پروفایل / خروج + کادر نام
* با شروع، بازی با موتور رسمی Solar2D 2026 (داخل game/engine) زیر Wine اجرا می‌شود

ابتدا یک پنجرهٔ «در حال اجرای بازی…» می‌بینی. اولین باری که یک پروفایل را
اجرا می‌کنی، Wine محیط خودش را می‌سازد (۱ تا ۳ دقیقه). اجراهای بعدی سریع است.

----------------------------------------------------------------
 داده‌ها و پروفایل‌ها
----------------------------------------------------------------
* پروفایل‌ها و نام‌ها و محیط Wine هر پروفایل:
      ~/.local/share/Fruitcraft/profiles/pN/
      (نام: profile.txt ، محیط Wine: wineprefix/)
* لاگ لانچر:  fruitcraft.log  کنار همین فایل
* هیچ فایلی در پوشهٔ اصلی/والد پخش نمی‌شود.

----------------------------------------------------------------
 رفع اشکال
----------------------------------------------------------------
* «Wine نصب نیست»:  sudo apt install wine64
* پنجرهٔ Wine Mono باز شد: آن را Cancel کن (بازی به Mono نیازی ندارد؛
  لانچر خودش جلوی این پیام را می‌گیرد).
* بازی اجرا شد ولی سیاه است: درایور گرافیک/میزکار خود را چک کن؛
  موتور به OpenGL 2+ نیاز دارد (روی Mesa/llvmpipe هم تست شد و کار می‌کند).
* گزارش ایران: متن فارسی در خود بازی، داخل Wine، درست و چسبیده رندر می‌شود
  (تست شده) - نیازی به تنظیم فونت نیست.

----------------------------------------------------------------
 چرخهٔ تغییرات
----------------------------------------------------------------
v0.1.11
  * نسخهٔ لینوکس اضافه شد: لانچر بومی (Python + Tk + Pillow) با همان
    طراحی و چیدمان راست‌به‌چپ نسخهٔ ویندوز، با تصاویر و فونت‌های خود بازی.
    متن‌های فارسی در زمان ساخت با HarfBuzz (libraqm) رندر می‌شوند، پس
    بدون وابستگی به shaper سیستم درست دیده می‌شوند.
  * موتور بازی همان Solar2D 2026 است که زیر Wine اجرا می‌شود
    (تست‌شده روی Wine 11.22 staging، Mesa llvmpipe، X صفر-کانفیگ).
  * هر پروفایل محیط Wine جداگانه دارد؛ داده‌ها در
    ~/.local/share/Fruitcraft/profiles/pN
  * لانچر اول‌بار که پروفایل اجرا می‌شود، محیط Wine را می‌سازد و پیام
    نصب Mono/Gecko را با WINEDLLOVERRIDES خاموش می‌کند.
  * پنجرهٔ بازی به «Fruitcraft» تغییر نام می‌دهد (با xdotool اگر باشد).
  * نسخهٔ ویندوز: پنجرهٔ بازی حالا واقعاً Maximize/بزرگ می‌شود و لانچر
    اندازهٔ آن را چک می‌کند؛ موتور جدید دیگر با APPDATA ریدایرکت‌شده
    کرش نمی‌کند؛ بازی به‌صورت پیش‌فرض فارسی اجرا می‌شود.

v0.1.10  (پایه)
  * مهاجرت به Solar2D 2026.3738، رفع read("a")، load(string)،
    استاب‌های plugin/*.lua، حذف resource.car، پنجرهٔ افقی 960x640،
    اجرای config.lu اصلی و اعمال دوبارهٔ ابعاد افقی، فارسی پیش‌فرض.
